# Дизайн-система

Один принцип: **технічний документ, а не лендинг.** Щільно, пласко, без
декору. Якщо елемент виглядає «гарно», але не додає інформації, його немає.

## Заборонено

| Ніколи                            | Чому                                                        |
| --------------------------------- | ----------------------------------------------------------- |
| Заокруглення понад 2px            | Скруглені картки з тінню це головна ознака шаблонного AI-UI |
| Тіні (`box-shadow`)               | Глибина тут не несе сенсу. `--shadow` дорівнює `none`       |
| Кольорові борди карток            | Колір лише крапкою або текстом бейджа                       |
| Градієнти, скло, blur як прикраса | Blur лишився тільки під мобільною шапкою                    |
| Кольоровий текст задля акценту    | Акцент дає вага і позиція, а не колір                       |
| Емодзі в інтерфейсі               | Іконки тільки lucide                                        |

## Шари

Порядок імпорту в `src/styles/global.css` має значення.

| Файл             | Що можна класти                                          | Чого не можна           |
| ---------------- | -------------------------------------------------------- | ----------------------- |
| `tokens.css`     | тільки значення в `:root` і `[data-theme=dark]`          | будь-які інші селектори |
| `base.css`       | reset і голі теги: `body`, `h1`, `p`, `table`, `a`       | класи                   |
| `components.css` | `.card`, `.grid`, `.tag`, `.rule`, `.bul`, `.prose`      | позиціювання сторінки   |
| `layout.css`     | `.shell`, `.side`, `.nav`, `.burger`, мобільна поведінка | вміст сторінок          |

Стилі, специфічні для однієї сторінки, лишаються в її `<style>`. Якщо той самий
блок знадобився двічі, він переїжджає в `components.css`.

## Токени

Кольори в oklch, окрім фірмового синього. Тема перемикається атрибутом
`data-theme` на `<html>`, усі значення перевизначаються в одному місці.

| Токен                         | Роль                                     |
| ----------------------------- | ---------------------------------------- |
| `--background` / `--card`     | тло сторінки / тло блока                 |
| `--elevated`                  | тло рядка таблиці і ховера               |
| `--foreground`                | заголовки і акцентний текст              |
| `--body`                      | основний текст абзаців                   |
| `--muted-foreground`          | підписи, метадані, іконки                |
| `--border` / `--border-soft`  | зовнішня рамка / внутрішній розділювач   |
| `--primary`                   | `#3c49ec` — узято з логотипу Alpina Tech |
| `--primary-soft`              | підкладка виносок                        |
| `--success` / `--destructive` | виконано / ризик                         |

Легасі-аліаси (`--ink`, `--line`, `--bg-2`, `--accent`) лишені навмисно: на них
спираються стилі сторінок. Нові стилі пишемо на основних іменах.

## Типографіка

Geist і Geist Mono. Заголовки `600`, щільний трекінг. Моноширинний шрифт тільки
для кодів, дат, ідентифікаторів процесів і `.kicker`.

| Клас      | Де                                       |
| --------- | ---------------------------------------- |
| `.kicker` | надпис над блоком, uppercase, 11px, mono |
| `.mono`   | ідентифікатори, дати                     |
| `.lnk`    | посилання в тексті                       |

## Кольори контурів

Кожен контур має `hue` у `src/data/units.ts`. Використовується **тільки** як:

- крапка `.dot`
- колір тексту бейджа `.tag`
- `stroke` вузла в Mermaid

Ніколи як заливка картки чи товстий бордер.

## Примітиви

`.card`, `.grid.g2`, `.grid.g3` (кожен прямий нащадок стає карткою), `.tag`
(`.primary`, `.soft`), `.rule` (виноска), `.bul` / `.bul.tick`, `.scroller`
(обгортка широкої таблиці), `.sec` + `.sec-head`, `.rise` (поява при
завантаженні).

Широкий вміст завжди всередині `.scroller`. Горизонтального скролу в `body`
бути не може.

## Іконки

lucide через `astro-icon`: `<Icon name="lucide:users" />`. Розміри: 16px у
навігації, 17px у заголовках секцій, 13px усередині тексту.

## Перевірка перед комітом

1. `document.documentElement.scrollWidth === clientWidth` на 375px
2. Обидві теми виглядають цілими
3. Жодного нового `border-radius` понад 2px і жодного `box-shadow`
